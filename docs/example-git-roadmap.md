## Overview

By completing this roadmap, you will be able to manage Git repositories for personal projects, collaborate effectively using feature branches, prepare clean and signed release branches for professional environments, and contribute to open source projects with performance optimization techniques. The four phases build progressively from establishing foundational Git skills through managing personal repositories, to collaborative workflows, professional release management, and finally advanced open source contributions. This plan suits developers who want a structured, hands-on approach to mastering Git over eight weeks with a steady weekly commitment.

## Getting started

1. Set up Git on your local machine and configure your user name and email as required for commits. 2. Create a new repository for your Personal Notes project, which is the milestone for phase 1 Foundations. 3. Complete the initial course in phase 1 to learn basic Git commands such as init, add, commit, and status. 4. Practice making commits and viewing the commit history within your Personal Notes repository. 5. Explore how to use branches locally to organize your notes. 6. Confirm you can create, switch, and merge branches without errors. When you can manage your Personal Notes repository confidently and understand basic branching, you are ready to move on to phase 2.

## Foundations — Foundations

`15 hours`

Acquire essential Git knowledge including repository setup, basic commands, and local version control workflows to confidently manage project history on a personal machine.

### What you will learn

- Installing Git on Windows, macOS, and Linux
- Initializing a Git repository with git init
- Cloning remote repositories using git clone
- Understanding the Git working directory, staging area, and repository
- Tracking file changes with git add and git status
- Committing changes with git commit and writing commit messages
- Viewing commit history using git log
- Undoing changes with git checkout and git reset
- Configuring user identity with git config
- Basic file operations: adding, modifying, deleting tracked files

### Milestone project

**Personal Notes Repository**

Create a local Git repository to track changes in a personal notes folder, demonstrating initialization, staging, committing, and viewing history.
